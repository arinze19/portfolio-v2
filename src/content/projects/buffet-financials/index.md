Buffet financials is a web application that helps individuals track and analyze their expenses across multiple accounts. It supports USD, NGN, and GBP currencies.
The application features user authentication, account management, transaction tracking, and data visualization through charts and graphs. It is built with a focus on security and user experience, ensuring that users can easily manage their finances in one place.
